# Mogu

Dock とメニューバーから開けるメモ帳（macOS 14 以降、Apple Silicon）。
⌃⌥⌘T でどこからでも開いて書き、殴り書きは Mac の中の Gemma 4 に推敲させられる。
⌃⌥⌘R で会議を録り始め、終えると文字起こしと要約がノートに入る。

- アプリは 2.2 MB と軽く、macOS の部品だけで組んである（依存するライブラリはない）。
  常駐しているのはアプリ1つだけで、CPU は 0%、メモリは 17 時間動かしたあとで約 110 MB だった。
  推敲の Gemma は ⌘J を押したときだけ起動し、5 分使わなければ止めてメモリを返す
- 推敲も議事録もこの Mac の中で完結し、文字も音も外に送らない。
  ネットにつながるのは、最初に llama.cpp、speech.cpp、モデルを取ってくる `setup.sh` だけ。
  アカウントも API キーも要らない
- ノートはただの `.md` ファイルとしてフォルダに置くので、Obsidian や Finder、git からもそのまま扱える。
  開いただけでは書き込まず、ほかのアプリでの変更も上書きしない

推敲も議事録も使わないなら、要るのはアプリだけ。
推敲と議事録の要約には llama.cpp（40 MB）と Gemma 4 E4B（約 5 GB）を、議事録の文字起こしには speech.cpp（20 MB）と Haas-ja（0.66 GB）を足す。

名前は殴り書きを「もぐもぐ」噛み砕いて文にすることから付けた。
音声入力の [Poko](https://github.com/pienmalu/poko) と対になる。

[inseven/thoughts](https://github.com/inseven/thoughts)（MIT）からの fork。
ただし中身は書き直していて、上流の変更はもう取り込めない。
上流のままのコードは `main` ブランチにある。

## 使い方

```bash
./scripts/build-app.sh --install --open   # アプリを作って ~/Applications に入れ、開く
./scripts/setup.sh                        # 推敲と要約を使うときだけ。llama.cpp と Gemma 4 E4B（約 5 GB）を取ってくる
./scripts/setup.sh meeting                # 議事録を使うときだけ。speech.cpp と Haas-ja（0.66 GB）を取ってくる
```

`--install` を付けると、`~/Applications/Mogu.app` に入る。
動いている Mogu は先に終了させてから入れ替える。
Dock に置くには、開いている間に Dock のアイコンを右クリックし、オプション → Dock に追加 を選ぶ。
同じメニューの「ログイン時に開く」で、Mac を起動したときに開くようにもできる。

- **⌃⌥⌘T**：どこからでも新しいメモを開く（フルスクリーンのアプリの上にも出る）。
  もう一度押すと隠れて、元のアプリに戻る
- **⌃⌥⌘R**：どこからでも議事録を始める。もう一度押すと終える
- Dock のアイコン：押すと窓を出す。右クリックのメニューからも、新しいメモと議事録を始められる
- メニューバーのアイコン：左クリックで出し入れ、右クリックでメニュー（議事録、保存先、推敲のモデル、終了）。
  議事録を録っている間は、赤い丸になる
- 窓を閉じても隠れるだけで、Mogu は終了しない。
  終了は ⌘Q か、メニューの「終了」
- 保存は自動。
  書くのをやめて 0.6 秒で書き込む。
  空のメモはファイルにしない

| キー | すること |
|---|---|
| ⌘N | 新しいメモ |
| ⌘P | ノートを探す（↑↓ で選び、Enter で開く。見つからなければ、その言葉で新しいメモを作れる） |
| ⌘R | 議事録を始める・終える |
| ⌘J | 推敲（選んだ範囲。選んでいなければ全体） |
| / | 行頭か空白のあとで打つと、コマンドのメニュー（見出し、ToDo、引用、コード、日付など）。日本語入力のままなら「；」でも出る |
| ⌘B・⌘I・⇧⌘X・⌘E・⌘K | 太字・斜体・取り消し線・コード・リンク（もう一度押すと外す） |
| ⌥⌘1〜3・⌥⌘0 | 見出し 1〜3・ふつうの文に戻す |
| ⌘↩ | ToDo にする・チェックを付け外しする |
| Tab・⇧Tab | 箇条書きを1段下げる・上げる |
| ⌃⌘↑・⌃⌘↓ | 行を上下に動かす |
| ⇧⌘C | 本文全体を Markdown でコピー |
| ⌘F | 本文の中を検索 |
| ⌃⌘S | 一覧を出し入れする（隠すと、書くだけの小さな窓になる） |
| ⌘W | 隠す |
| ⌘Q | 終了 |

## ノートのファイル

- 保存先は既定で `~/Notes`。メニューから変えられる（サブフォルダの中も一覧に出る）
- 新しいメモは `20261111-083000.md` のような日時の名前で作る。
  一覧には本文の 1 行目が出る。
  自分で付けた名前のファイル（`会議メモ.md` など）は、その名前で出る
- 開いただけでは書き込まない。
  frontmatter、BOM、改行コード（CRLF）は読んだときのまま残す
- ほかのアプリで書き換えられたら、手元に未保存の変更がなければ読み直す。
  あれば上書きせず、
  `〜 の競合コピー.md` に保存する
- 削除はゴミ箱へ移すだけ（一覧の右クリック）
- 更新日時だけ変わって本文が同じとき（同期ツールなど）は、競合とみなさない

## 見た目とコピー

文字はプレーンな Markdown のまま持ち、見た目だけを付ける。
カーソルのない所では記号（`#`、`**`、`` ` ``、リンクの URL など）を隠し、箇条書きは •、ToDo はチェックボックスで見せる。
カーソルを置いた所だけ、記号が出てきて直せる（見出しはその行、太字やリンクはその語、ToDo は記号の中に入ったとき）。
隠すのは見た目だけなので、コピーもペーストも常に Markdown の文字になる。
ほかのアプリから書式つきの文を貼っても、文字だけが入る。

- チェックボックスは押すと切り替わる。行頭で `[]` と打って空白を打つと、ToDo になる
- 箇条書きの行で Enter を押すと、次の行にも記号が入る（空の行でもう一度押すと抜ける）
- 文字を選んで URL を貼ると、選んだ文字がリンクになる。リンクは ⌘クリックで開く（ふつうのクリックはカーソルを置くだけ）
- 記号をいつも見せたいときは、`Theme.swift` の `hidesMarkers` を `false` にする

色と大きさは `Sources/Mogu/Theme.swift` だけで変えられる。

## 議事録

⌘R（どこからでも ⌃⌥⌘R）を押すと、新しいノートを作って録り始める。
録っている間は、本文の下に小さなバーが出て、経過時間と、いま聞こえた文が流れる。
その間、ノートにはふつうにメモを書ける。
もう一度押すか「終える」を押すと、ノートの終わりに `## 文字起こし` が入り、少しして `## 要約`・`## 決定事項`・`## TODO` がその前に入る。

- マイクの声（自分）と、Mac から出る音（オンライン会議の相手）を、別々に文字にする。
  相手の声が一度でも聞こえた会議だけ、発言に **自分**・**相手** が付く（対面の会議では付かない）
- Mac から音が出ている間は、マイクの音を使わない。
  スピーカーから出た相手の声をマイクが拾って、同じ発言が2回書かれるのを防ぐため。
  イヤホンでも同じなので、相手と同時に話した言葉は落ちる。変えるときは `MeetingSession.swift` の `otherThreshold`
- Mac から出る音を取れるのは macOS 14.2 以降。それより前は、マイクだけで録る
- 初回は「マイク」と「システム音声の録音」の許可を求められる。
  簡易署名（`codesign -`）のアプリは、ビルドし直すたびに聞き直される。
  自分の署名があるなら `MOGU_SIGN_IDENTITY="Apple Development: …" ./scripts/build-app.sh --install` で1回で済む
- 文字起こしも要約も、エディタを通して入れるので ⌘Z で戻せる。
  要約ができたときに別のノートを開いていたら、バーに「ノートに入れる」が出る
- 要約は Gemma 4 に頼む（推敲と同じモデル）。`setup.sh` をしていなければ、文字起こしだけが入る。
  長い会議は 6,000 字ずつ要点を抜き出してから、まとめる
- 窓を隠しても録り続ける。録ったまま終了すると、文字起こしをノートに入れてから終わる
- アプリが落ちても、それまでの発言はキャッシュに控えてあり、次に開いたときに新しいノートになる
- 音声そのものは保存しない
- 誰が話したか（話者分離）は、自分と相手の2つまで。相手が何人いても「相手」になる

M4 で、合成した 20 秒の会議は、文字起こしが 0.5 秒、要約が 7 秒だった。
本物の会議、マイク、許可の案内は、まだ確かめていない。

## 推敲

⌘J で、選んだ範囲を Gemma 4 に推敲させる。
結果はシートで見せ、「置き換える」を押したときだけ本文に入る（⌘Z で戻せる）。
シートでは「変更点」（削った字に取り消し線、足した字に下線）と「結果」（直した後の文だけ）を切り替えられる。

- llama.cpp の `llama-server` を、使うときだけ起動する（127.0.0.1 だけで待ち受ける）。
  5 分使わなければ止めてメモリを返す
- アプリが落ちて `llama-server` だけが残ったら、次の起動で片付ける
- 一度に推敲できるのは 5,000 字まで。
  それより長いときは範囲を選ぶ。
  長いほど時間がかかる（E4B で 4,500 字に約 2 分）
- 書き切れずに途中で止まった答えは、完成したものとして見せない
- モデルはメニューの「推敲のモデル」で選ぶ。
  M4、24 GB で測った値は次のとおり

| モデル | ファイル | 動いている間のメモリ | 速さ | 文 |
|---|---|---|---|---|
| E4B（既定） | 5.0 GB | 約 5.0 GB | 約 30 トークン/秒 | 自然 |
| E2B | 3.1 GB | 約 3.1 GB | 約 55 トークン/秒 | やや硬い |

起動は、ファイルが OS に読み込まれていれば 1 秒ほど、久しぶりだと 10 秒ほどかかる。
E2B を使うときは `./scripts/setup.sh e2b` で取ってくる。
モデルの実体は `~/models/llama.cpp` に置き、`models/` にはリンクだけを張る。
ほかのアプリからも同じファイルを使えるようにするためで、置き場所は `LLAMA_MODEL_DIR` で変えられる。

## 軽さ

常駐しているだけなら CPU は 0%。
メモリ（phys_footprint）は、17 時間動かしたあとで約 110 MB だった（M4）。
依存するライブラリはなく、アプリは 2.2 MB。

## 開発

```bash
./scripts/test.sh                       # テスト
./tools/render.sh build/shots --window  # 見た目を PNG に描く（--window は窓全体。画面に一瞬出る）
./tools/try-rewrite.sh e4b < 下書き.txt  # アプリと同じ経路で推敲を試す
./tools/try-meeting.sh 会議.wav          # 録音を、アプリと同じ経路（文字起こし → 要約）に流す
./tools/render-app-icon.sh              # アイコン Resources/AppIcon.icns を、正方形の絵 Resources/AppIcon.png から作り直す
```

- アプリ名と bundle ID は `scripts/build-app.sh` の先頭 2 行で変えられる。
  ホットキーは `Sources/Mogu/GlobalHotKey.swift` の先頭にある
- アプリはビルドしたフォルダ（`Info.plist` の `MoguHome`）の `vendor/` と `models/` を使う。
  `~/Applications` に入れたアプリも同じで、フォルダを動かしたらビルドし直す
- アイコンの絵は自作アプリで共通の黒いスライム（`~/workspace/dev/brand/black-slime`）から描いた。
  描き方とほかの案はそちらの README にある
